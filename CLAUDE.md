# CLAUDE.md

This is the **riscv-unified-db (UDB)** repository.

The active LFX work in this branch is **architectural parameter extraction**,
which lives entirely under **`param_extraction/`**. If you are working on that
project, read **`param_extraction/CLAUDE.md`** first — it has the rules, the
review process, how to handle the mentor's Excel feedback, and the current
state. Authoritative rules: `param_extraction/INCLUSION_CRITERIA.md`. Pipeline
run guide: `param_extraction/README.md`.

For the broader UDB codebase (Ruby gems, IDL, schemas, spec YAML), see the
repository's top-level `README.adoc`, `CONTRIBUTING.adoc`, and `doc/`.
